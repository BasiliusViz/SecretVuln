# SecretVuln — дизайн-система и локализация

Продукт делается для русскоязычного рынка. **Весь UI — на русском.** Код, API,
значения enum'ов в БД — на английском; перевод происходит только на фронтенде.

## Локализация

- Библиотека: `react-i18next` (даже при одном языке — все строки через `t()`,
  чтобы не размазывать текст по компонентам; плюс встроенная плюрализация)
- Русская плюрализация обязательна: «1 находка / 2 находки / 5 находок»
- Даты: `DD.MM.YYYY`, время 24ч, разделитель тысяч — пробел (`Intl` с локалью `ru-RU`)
- Словарь терминов (единый по всему UI):

Термины интерфейса менялись: «Активы» → **«Проекты»**, «Находки» →
**«Уязвимости»**. В коде, API и БД остались английские `Entity` и `Finding`.

|-------------------|---------------------|
| Entity            | Проект              |
| Finding           | Уязвимость          |
| Import            | Импорт              |
| Dashboard         | Дашборд             |

| critical/high/medium/low/info | Критичная / Высокая / Средняя / Низкая / Инфо |

## Типографика

**Шрифт: Inter** (или Golos Text как альтернатива). Причина: полная и качественно
нарисованная кириллица — у многих популярных UI-шрифтов кириллицы нет вообще или
она автосгенерирована. Golos Text разработан специально под русский язык
(используется в госсервисах РФ) и тоже подходит. Моноширинный для путей/кода:
JetBrains Mono (кириллица есть).

## Цвета

### Почему так

1. **Критичность — по отраслевой конвенции** (CVSS, DefectDojo, Qualys, GitLab):
   красный → оранжевый → янтарный → синий → серый. Безопасники ожидают именно
   эту шкалу — менять её значит увеличивать время чтения дашборда.
2. **Дальтонизм**: ~8% мужчин имеют нарушение цветовосприятия (в ИБ-командах
   мужчин большинство, т.е. в среднем ~1 из 13 пользователей). Поэтому:
   severity НИКОГДА не кодируется только цветом — всегда цвет + текст + иконка.
   «Низкая» — синяя, а не зелёная (красно-зелёная пара неразличима при
   дейтеранопии, самой частой форме).
3. **Акцент — синий**: в кросс-культурных опросах предпочтений цвета синий
   стабильно на первом месте (~40–57%, в т.ч. в России); это стандарт
   enterprise-инструментов, он не конфликтует со шкалой severity (в ней синий —
   только «низкая», самый спокойный уровень).
4. **Контраст — WCAG 2.1 AA** (≥4.5:1 для текста).
5. **Тёмные темы**: по опросам Stack Overflow Developer Survey ~70%+
   разработчиков предпочитают тёмные темы; SOC-инструменты (Grafana, Kibana)
   по умолчанию тёмные. Светлая остаётся для тех, кто работает днём.

### Пять тем

Переключаются атрибутом `data-theme` на `<html>`, значения — в
`src/theme/global.css`, список — в `src/theme/themes.ts`, состояние — в
`src/theme/ThemeContext.tsx` (сохраняется в localStorage).

| Тема | id | Фон | Акцент |
|------|----|-----|--------|
| Янтарный терминал (по умолчанию) | `amber` | `#0A0705` | `#FFB02E` |
| Кибер-бирюза | `cyber` | `#05090B` | `#19D3C5` |
| Индиго | `indigo` | `#0B1020` | `#8B7BFF` |

### Стиль тёмных тем

- Заголовки, названия разделов и крупные числа — **JetBrains Mono, капсом, с
  разрядкой** (`h1`, `.section-label`, `.metric` в global.css).
- Фон — тонкая сетка 24px из переменной `--grid` (в светлой теме прозрачная).
- **Свечение (`--glow`) только на акцентах**: заголовки, логотип, крупные
  цифры метрик. В таблицах и формах свечения нет — читаемость важнее эффекта.
  (Раньше здесь было правило «никаких эффектов»; изменено осознанно.)
- Плоские поверхности, тонкие границы, без градиентов и теней.

### Токены severity

Каждая тема задаёт `--sev-{severity}` (сплошной цвет для графиков и рамок) и
пару `--sev-{severity}-{bg,text}` для бейджей. Порядок и смысл одинаковы во
всех темах: критичная — красно-малиновая, высокая — оранжевая, средняя —
жёлтая, **низкая — синяя (не зелёная)**, инфо — серая.

Светлая тема (эталон контраста):

| Severity | RU        | Основной | Фон бейджа | Текст бейджа | Иконка (Tabler) |
|----------|-----------|----------|------------|--------------|-----------------|
| critical | Критичная | `#A32D2D` | `#FCEBEB` | `#791F1F`    | alert-octagon   |
| high     | Высокая   | `#D85A30` | `#FAECE7` | `#712B13`    | alert-triangle  |
| medium   | Средняя   | `#BA7517` | `#FAEEDA` | `#633806`    | alert-circle    |
| low      | Низкая    | `#378ADD` | `#E6F1FB` | `#0C447C`    | info-circle     |
| info     | Инфо      | `#888780` | `#F1EFE8` | `#444441`    | circle-dashed   |

Recharts берёт цвета из переменных активной темы через
`useSeverityColors()` (`src/theme/severity.ts`) — хардкодить цвета в графиках
нельзя, иначе они не переключатся вместе с темой.

### Статусы уязвимостей

- Новая — синий (акцент), В разборе — янтарный, Подтверждена — оранжевый,
  В работе — фиолетовый, Исправлена — зелёный, Ложное срабатывание / Риск принят — серый.

## Layout

- Левый сайдбар (фикс. ~200px): Дашборд, Проекты, Уязвимости, Импорты,
  Группы и доступ, Роли; внизу — выбор темы и пользователь
- Контент: карточки метрик по severity сверху (с цветной верхней границей),
  ниже — конфигурируемые виджеты (Recharts), таблицы с бейджами
- Таблица уязвимостей — самый частый экран: плотная, фильтры по severity/
  статусу/сканеру/проекту в шапке, сортировка, пагинация server-side
